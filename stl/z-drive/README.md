# STL – Z drive diagnostics

Parts used by [Z drive diagnostics](../../docs/z-drive-diagnostics.md).

| File | What | Status |
|---|---|---|
| `zhop_islands_test.stl` / `.step` | Test print for z-hop settings: 60 × 60 × 1 mm plate + 6 × 6 cylinders Ø6 × 4 mm. Each layer of the cylinders = 36 travels with retraction and z-hop. Generated by `zhop_islands_test.py` (FreeCAD 1.0). | ready |
| `lis3dh_bed_mount.stl` | Holder for the LIS3DH accelerometer board on the bed frame (Z axis vertical, close to a leadscrew corner). | *placeholder – to be added* |
| `lis3dh_cable_clip.stl` | Strain relief for the accelerometer cable on the moving bed. | *placeholder – to be added* |

The probe itself (Zcythe, K0) is a separate project with its own STL files:
[Zcythe.3d-printer-bed-probe](https://github.com/grzechot/Zcythe.3d-printer-bed-probe).
